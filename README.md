# Stranger
## Stranger is a simple game in which a man has broken into your house, its a more of a short demo horror game.

**Story**: You wake up hearing a noise in the kitchen. a random stranger is in your house!

At the moment the game only runs on Windows x64! However you can run it yourself for your supported platform by running the game directly from source.

### Releases
[Beta 0.1
](https://github.com/officialmelon/stranger/releases/download/0.1/Release-Beta.zip)
### From Source
Install Love2D, run `love .` in the directory

- It takes around 3 minutes to complete
- The game itself doesnt have much SFX

The game is made in love2d (lua, 2d engine)
If you want to check out my lapses for asset development, check the user melon if you do.
