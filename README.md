# Stranger
## Stranger is a simple game in which a man has broken into your house, its a more of a short demo horror game than a full sized game.

The game was intended to be a longer game however that was too out of scope, so I scrapped together this short demo game which most likely has bugs since it isnt extensively tested :P

### Releases
[Beta 0.1
](https://github.com/officialmelon/stranger/releases/download/0.1/Release-Beta.zip)
### From Source
Install Love2D, run `love .` in the directory

- It takes around 5 minutes to complete
- The game itself doesnt have much SFX
